## Changes

- Explore uses the deployed `peaks_in_bounds(..., max_rows)` signature and reads routes through visible peak slugs. Errors are visible and retryable; superseded viewport requests are cancelled. Wrapped longitudes are handled.
- Route browsing no longer reads the deleted `route_peaks` table or `routes.features`. Sorting, pagination, highpoint, summit, route-type, distance and catalogue difficulty filters use the current schema. Unnamed mapped routes are included.
- Search, route detail, lists and profile distinguish failures from empty/missing results. Your lists explicitly filter by your user id; public-list readers are not shown remove controls.
- Downloads use a reply port before service-worker control, bounded readiness/timeouts, exact byte counts and explicit failure for incomplete maps. Database cache fallback preserves query parameters. Downloaded HTML is refreshed rather than taking old chunk URLs from the shell cache. Downloads/activity index chunks and PWA icons are cached.
- Both map styles use 512px imagery; the lossless 512px DEM remains unchanged. Estimates use a full measured tile plan, with approximate labels and actual saved byte counts.
- Terrain sampling respects the point budget and rejects non-finite DEM readings. Tests cover spacing, median noise suppression, gentle ascent, jitter, descent, timing and hazard boundaries.
- Added 70 source-checked peaks, including 40 Canadian summits, plus South America, Africa, Oceania, Antarctica, Nepal and Pakistan. All 70 matched encyclopedia articles; 68 have attributed photographs.
- Targeted enrichment now respects the resume log and `--retry-misses --only` stays scoped. Removed two exact duplicate photo records. The audit measures distance to route segments, preserving its 200 m tolerance; simplification had made two valid routes fail a vertex-only check.
